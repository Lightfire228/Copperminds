# Copperminds

This is a utility for me, by me, specifically tailored to my [Obsidian](https://obsidian.md/) vault

It is a tool for sorting through my obsidian vault (en masse), using Obsidian's [frontmatter](https://obsidian.md/help/properties) properties.


On top of those properties, is my implementation of the [Getting Things Done](https://www.amazon.com/Getting-Things-Done-Stress-Free-Productivity-ebook/dp/B00KWG9M2E) workflow
